Cadastro de Equipamentos em C

 

 Funcionalidades:
- Cadastrar equipamentos.
- Informar nome, código de identificação e localização.
- Salvar os dados no arquivo `equipamentos.txt`.
- Listar os equipamentos cadastrados.
- Preservar os registros ao adicionar novos equipamentos.

 Utilizadas:
- Linguagem C.
- Manipulação de arquivos TXT.
